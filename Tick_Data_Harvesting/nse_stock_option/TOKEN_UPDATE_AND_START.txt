================================================================================
STEP 4: GENERATE SHAREKHAN ACCESS TOKENS
================================================================================

For api1 client:
  python auth_helper.py --client api1

What to do:
  1. A browser login URL will be printed on screen
  2. Open the URL and log in with your Sharekhan account
  3. After login, browser redirects to: https://redirect/?RequestToken=XXXX
  4. Copy the RequestToken value (everything after RequestToken=)
  5. Paste it when prompted: "Enter RequestToken: [PASTE HERE]"
  6. Script saves token to config.json automatically

For api2 client (if using dual API):
  python auth_helper.py --client api2

Repeat the same process with your second Sharekhan account.

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "access_token is missing"
  → Run: python auth_helper.py --client api1
  → Make sure you paste the correct RequestToken

Issue: "Connection refused" or "WebSocket failed"
  → Check internet connectivity
  → Verify Sharekhan API credentials in config.json
  → Check if trading hours (9:00 - 15:45 IST) - harvester auto-sleeps outside hours

Issue: "File not found" (fo_symbols_api1.txt)
  → Verify all files exist: ls -la
  → Ensure you're in: /home/ubuntu/nse_stock_option/

Issue: Process crashes
  → Check logs: cat harvester.log | tail -50
  → Verify config.json is valid JSON: python -c "import json; json.load(open('config.json'))"

================================================================================
IMPORTANT NOTES
================================================================================

1. TOKENS EXPIRE DAILY
   → Run auth_helper.py every morning before starting harvester
   → Tokens are saved automatically to config.json

2. MARKET HOURS ONLY
   → Harvester collects data: 9:00 AM - 3:45 PM IST (Monday-Friday)
   → Outside market hours: process sleeps and waits for next session
   → No trading on NSE holidays (defined in nse_holidays.txt)

3. STRIKE WINDOW
   → Always collects 21 strikes: ATM ± 10 (per your specification)
   → Covers both CE and PE options
   → ~42 total contracts per stock symbol

4. DUAL API SUPPORT
   → api1 and api2 run as parallel workers
   → Data written to separate folders: tick_data/api1/ and tick_data/api2/
   → Each has its own symbols file and output directory

5. DATA ORGANIZATION
   → tick_data/api1/DD-MM-YYYY/SYMBOL.csv
   → tick_data/api2/DD-MM-YYYY/SYMBOL.csv
   → New date folder created automatically at midnight rollover

6. GRACEFUL SHUTDOWN
   → Press Ctrl+C to stop (foreground)
   → Process flushes buffered ticks before exiting
   → All data is saved to CSV files
